# JoianDent website

Fișiere:
- index.html
- styles.css
- script.js
- assets/

Pentru test local:
1. Deschide folderul în VS Code.
2. Instalează extensia Live Server.
3. Click dreapta pe index.html -> Open with Live Server.

Pentru publicare pe Vercel:
1. Creează cont GitHub și un repository nou.
2. Urcă toate fișierele din folder.
3. În Vercel: Add New -> Project -> Import repository.
4. Framework preset: Other.
5. Deploy.
